# VAE for Hybrid Language Music Clustering

This repository contains the implementation of an unsupervised learning pipeline based on **Variational Autoencoders (VAE)** for clustering **hybrid-language music** (English and Bangla).  
The project was developed in **Google Colab** and later modularized for reproducibility and GitHub submission.

The goal is to learn compact latent representations from combined **audio features** and **lyrics features**, and to evaluate clustering performance against a **PCA + K-Means baseline**.
